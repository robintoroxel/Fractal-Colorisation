Four ways to colour artanh(z8)

Each panel shows the same function on the same grid with the same palette. Only the rule that maps a value to a position on the palette changes, so differences between panels come from the technique alone.

Hover a panel to read z and f(z).

f(z) = artanh(z8) = ½·[log(1 + z8) − log(1 − z8)], principal branch. It has 16 logarithmic singularities on the unit circle where z8 = ±1, and branch cuts running outward from them along the rays where z8 is real with |z8| > 1. Grid: 560 × 560 samples.
